# ZEMARO Player – review demo playlist

This folder contains a **synthetic** test playlist for app reviewers (for example the Google Play "App access" instructions).

- `test.m3u` lists 3 live test channels (HLS), 2 test films and 2 test series episodes (MP4).
- Every video was generated with ffmpeg: color bars, test patterns, a counter and sine tones. There are no real channels, films or third-party content.
- ZEMARO Player is a media player only. It does not provide, sell or recommend any content; users add their own sources.
- This playlist is not built into the app and is not offered inside it.

`SHA256SUMS` lists the checksums of all files.
